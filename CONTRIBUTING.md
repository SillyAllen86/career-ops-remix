# Contributing

Thanks for improving Career-Ops Remix.

## Before you start

- Read `CAREER_OPS_AGENT.md`
- Keep user-specific data in user-layer files only
- Do not put private candidate information in shared system files

## Good contribution shape

- Small, focused pull requests
- Clear summary of behavior change
- Tests or verification steps when relevant

## Review checklist

- [ ] I followed the data contract
- [ ] I did not add personal data to shared files
- [ ] I verified the change locally
- [ ] I updated docs if behavior changed
