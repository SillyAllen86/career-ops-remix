# Governance

Career-Ops Remix is maintained as a lightweight open-source template.

## Principles

- Keep the workflow simple and inspectable
- Prefer shared, reusable logic over one-off hacks
- Keep user-specific content in user-layer files
- Accept contributions that improve clarity, reliability, or portability

## Decision model

- Maintainers approve merges
- Issues document design changes before large refactors
- Contributors should not overwrite each other's work

## Ownership

This repository is a remix of the original Career-Ops project. Credit the upstream project in documentation and keep attribution visible when you redistribute it.
